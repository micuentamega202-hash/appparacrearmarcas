Configuración inicial (una sola vez):
1. Creá una cuenta gratis en supabase.com → New project.
2. En SQL Editor pegá y ejecutá:
create table planner (user_id uuid primary key references auth.users(id), data jsonb, updated_at timestamptz default now());
alter table planner enable row level security;
create policy "own" on planner for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
3. En Authentication → Emails → plantilla "Magic Link": agregá {{ .Token }} al cuerpo del mail para recibir el código.
4. En Project Settings → API: copiá la URL y la anon key y pegalas arriba.
Con la sesión iniciada, todo se sincroniza solo y podés entrar desde cualquier dispositivo. Sin configurar, la app sigue funcionando 100% en local.
